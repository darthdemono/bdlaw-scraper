# Security policy

Report a suspected vulnerability privately through
[GitHub's reporting form](https://github.com/darthdemono/bdlaw-scraper/security/advisories/new)
or the address on the [maintainer's profile](https://github.com/darthdemono). Do not open a public issue.
Include a minimal reproduction and the impact. Reports are acknowledged within seven days.

Scope: the scraper fetches public pages and writes files. Things that count: a crafted page that makes it write outside the output directory or run code.
